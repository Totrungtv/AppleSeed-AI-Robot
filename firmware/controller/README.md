# ESP32 TFT controller

Snapshot ung vien duoc tim thay: `archive/AppleSeed_ESP32_V3_3_HYBRID_WIFI_MANAGER_FIX2.ino`.

Theo source:
- GT911 touch: SDA21, SCL22, INT32, RST33.
- UART2: RX16, TX17, 9600 baud toi UNO.
- USB Serial: debug/upload 115200.
- AP SSID: APPLE_SEED_ROBOT.
